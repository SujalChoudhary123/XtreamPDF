# XtreamPDF

XtreamPDF is a modern full-stack PDF tools platform that provides multiple utilities for editing, converting, organizing, and managing PDF files directly in the browser.

The project combines a polished frontend experience with a lightweight Node.js backend for session-based PDF editing and exports.

---

# Features

XtreamPDF includes a wide range of PDF utilities:

* Merge PDF
* Split PDF
* Extract Pages
* Delete Pages
* Rotate PDF
* Reorder Pages
* Watermark PDF
* Add Page Numbers
* Add Text
* Images to PDF
* PDF to Images
* Compress PDF
* Unlock PDF
* Protect PDF
* OCR PDF
* eSign PDF
* HTML to PDF
* PDF to Word
* Word to PDF
* Scan to PDF
* Compare PDFs

Some tools work fully in the browser, while advanced editing flows communicate with the backend API.
